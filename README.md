# translator
Маленькое окно поверх всех окон для Windows: раз в секунду читает текст под курсором мыши через UI Automation и автоматически переводит его с английского на русский. Четыре встроенных движка перевода с автопереключением при сбоях. Требует прав администратора.

EN → RU Translator Under Cursor

Маленькое always-on-top окно для Windows, которое переводит английский текст на русский прямо под курсором мыши.

Как это работает. Программа раз в секунду определяет элемент интерфейса Windows под курсором через UI Automation (то же API, что использует Narrator), читает текст этого элемента (свойство Name), и если текст на английском — переводит его на русский. Оригинал и перевод показываются в маленьком окне, которое всегда поверх остальных.

Требования. Windows 10 или 11, Python 3.9 или новее, права администратора. Без прав администратора UI Automation вернёт ошибку Access is denied при попытке прочитать UI чужих процессов — это политика безопасности Windows, обойти её нельзя.

Установка. Открой терминал в папке проекта и выполни: pip install -r requirements.txt. Или вручную: pip install uiautomation requests.

Запуск. Закрой PyCharm или терминал, запусти его от имени администратора (правый клик по ярлыку → «Запуск от имени администратора»), затем выполни: python translator.py.

Использование. Запусти программу — появится маленькое окно в углу экрана. Наведи курсор мыши на любой английский текст в браузере, редакторе или любой другой программе. Через секунду в окне появится перевод. Внизу мелким шрифтом видно, какой движок справился с переводом. Окно реагирует только на текст с латинскими буквами — русский текст под курсором игнорируется, так и задумано.

Движки перевода. Программа перебирает четыре движка по очереди. Если один упал — идёт к следующему. MyMemory — собственный API, лимит 5000 символов в день. Lingva — публичный прокси Google Translate, без ключа. SimplyTranslate — ещё один публичный прокси Google Translate, без ключа. Google напрямую — резервный вариант, часто отдаёт ошибку 429 (Too Many Requests). Если у тебя часто падает MyMemory по лимиту — открой translator.py и впиши свой e-mail в константу MYMEMORY_EMAIL. Лимит поднимется до 50000 символов в день.

Ограничения. UI Automation видит текст только у приложений, которые его экспортируют. Все нативные Windows-приложения, а также Chrome, Edge и Firefox — экспортируют. Некоторые игры и программы с кастомным рендерингом — нет, там программа текст не увидит. Программа не работает на Linux и macOS, потому что uiautomation — Windows-only. Ошибка Access is denied означает, что нужно запустить программу от имени администратора.

Структура проекта. translator.py — основной файл приложения. requirements.txt — список зависимостей. README.md — этот файл. .gitignore — список того, что не нужно коммитить.
