Перевод английского
под курсором мыши

Маленькое окно поверх всех окон для Windows: раз в секунду читает текст под курсором и переводит с английского на русский.

Условие. Требует прав администратора: чтение интерфейса идёт через UI Automation.

Что это умеет

📌

Без копирования

Навели курсор на английский текст — перевод появился сам. Выделять и вставлять не нужно.

🔁

Четыре движка

Встроено четыре движка перевода с автопереключением, если один не ответил.

🪟

Поверх всех окон

Окно всегда сверху и почти не занимает места на экране.
